# Week 1 — Cybersecurity Glossary

| Term | Short meaning |
|---|---|
| Asset | Valuable item or information to protect |
| Threat | Potential cause of harm |
| Vulnerability | Weakness in a system or process |
| Exploit | Method/code that takes advantage of a weakness |
| Risk | Likelihood and impact of harm |
| Attack surface | All possible entry/exposure points |
| Malware | Malicious software |
| Phishing | Deceptive message to steal information or deliver malware |
| Spear phishing | Targeted phishing |
| Whaling | Phishing targeting senior/high-value people |
| Vishing | Voice-call scam |
| Smishing | SMS scam |
| Social engineering | Manipulating people to bypass security |
| Ransomware | Malware that locks/encrypts data for extortion |
| Spyware | Software that secretly monitors or collects information |
| Trojan | Malicious software disguised as legitimate |
| Worm | Malware that can self-propagate |
| Virus | Malware that attaches to a host file/program |
| DoS | Denial of Service |
| DDoS | Distributed Denial of Service |
| MitM | Man-in-the-Middle |
| Brute force | Repeatedly guessing passwords/keys |
| Spoofing | Faking identity/source information |
| IDS | Intrusion Detection System |
| IPS | Intrusion Prevention System |
| SIEM | Security Information and Event Management |
| MFA | Multi-Factor Authentication |
| VPN | Virtual Private Network |
| PII | Personally Identifiable Information |
| CIA triad | Confidentiality, Integrity, Availability |
| Defense in depth | Multiple layers of security controls |
| Patch | Software update that fixes issues, including vulnerabilities |
| Zero-day | Vulnerability exploited or known before a usable fix is available |
