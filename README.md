## How I document practical work
For each lab, I record:
1. Objective — what I wanted to understand or test.
2. Environment — tool, operating system and lab used.
3. Steps — what I did, in my own words.
4. Observation — what happened and what the output means.
5. Learning — what I understood.
6. Evidence — screenshots or sanitized sample output.

**Ethics:** All security testing is performed only on systems I own or have explicit permission to test. I do not upload passwords, API keys, private data, real victim information or sensitive logs.
